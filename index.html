Skin Mask Mobile V4

Illustrations, game characters, and photos · Offline image editor

Your image stays on your device. No external libraries or server upload.

Brush: drag to paint or restore. Region: tap a connected area of similar color. Restore region can undo an over-censored area. Region selection stops at strong color differences, but is not perfect.

Automatic detection is intentionally cautious. It uses color clustering and region limits, not an AI trained to recognize fictional characters. Some images will need manual corrections. Running auto-detect replaces the current mask; Undo can restore it.
