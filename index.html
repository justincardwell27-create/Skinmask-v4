Skin Mask Mobile V5

AI-first censoring · Face and exposed skin controls · Mobile editor

Images are processed in your browser. The AI model and runtime must download from the internet on first use; images are not sent to a server by this app.

Uses MediaPipe's actual six-class person segmentation model, not global skin-color thresholds. It separates face skin from body skin, but was primarily trained on photos; anime and game characters may still be missed or misclassified.

AI needs internet access to load the runtime and model. If the network blocks these files, detection will report an error rather than silently switch to inaccurate color detection.

Manual correction is optional. Drag on the preview to add or remove censorship.
